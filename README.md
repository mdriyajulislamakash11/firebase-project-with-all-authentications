# AuthVerse 🌐🔐

Welcome to **AuthVerse** – a modern authentication-based React application supporting email/password login as well as third-party logins like Google, GitHub, and Facebook.

🔗 **Live Site:** [https://aquamarine-lily-6607c1.netlify.app/](https://aquamarine-lily-6607c1.netlify.app/)

---

## ✨ Features

- 🔐 Firebase Authentication
  - Email/Password Login
  - Google Login
  - GitHub Login
  - Facebook Login
- 🧑‍💼 User Profile Route (Protected)
- 🏠 Home, About, Contact Us Pages
- 🚀 Private Routing using React Router
- 📦 Context API for Global Auth State
- 🖼️ Responsive UI using Tailwind CSS & DaisyUI

---

## 🛠️ Technologies Used

- **React.js**
- **Firebase Authentication**
- **React Router DOM**
- **Tailwind CSS**
- **DaisyUI**
- **Netlify (Deployment)**
